# TEST Repository

## Download della cartella nuova_cartella

Per scaricare solo la cartella `nuova_cartella`, consulta le istruzioni dettagliate nel file [DOWNLOAD_INSTRUCTIONS.md](DOWNLOAD_INSTRUCTIONS.md).

### Quick Start

**Linux/Mac:**
```bash
curl -O https://raw.githubusercontent.com/RikMark/TEST/main/download_nuova_cartella.sh
chmod +x download_nuova_cartella.sh
./download_nuova_cartella.sh
```

**Windows/Tutti i sistemi:**
Scarica l'intero repository come ZIP da GitHub e estrai la cartella `nuova_cartella`.
